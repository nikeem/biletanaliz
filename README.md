# biletanaliz

Streamlit-приложение для анализа покупателей билетов.

- 1 xlsx-файл = 1 матч, каждая строка с email = одно купленное место.
- Показывает, какие email покупали билеты на все n матчей, на n-1, на n-2 (глубина настраивается).
- Для каждого email: сколько мест на каждом матче и какие матчи пропущены.
- Выгрузка полного отчёта в Excel и списков email в .txt.

Матчи сортируются по дате из имени файла (например `05_09_26.xlsx`).

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой

share.streamlit.io → New app → репозиторий `nikeem/biletanaliz`, ветка `main`, файл `app.py`.
